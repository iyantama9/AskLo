# Tutorial: Setup Domain & HTTPS untuk askcore.dev

## 🎯 Langkah 1: Pointing Domain ke Server

### A. Login ke Dashboard Domain Registrar Anda

Tergantung dimana Anda beli domain (Namecheap, GoDaddy, Cloudflare, dll), masuk ke dashboard domain management.

### B. Update DNS Records

Tambahkan 2 DNS records berikut:

#### Record 1: Root Domain (@)
```
Type: A
Name: @ (atau kosong, atau askcore.dev)
Value: 178.128.59.20
TTL: 3600 (atau Auto)
```

#### Record 2: WWW Subdomain
```
Type: A
Name: www
Value: 178.128.59.20
TTL: 3600 (atau Auto)
```

### C. Contoh untuk Berbagai Provider

#### **Cloudflare:**
1. Pilih domain "askcore.dev"
2. Klik tab "DNS"
3. Klik "Add record"
   - Type: A
   - Name: @
   - IPv4 address: 178.128.59.20
   - Proxy status: OFF (DNS only) - PENTING!
   - TTL: Auto
   - Save
4. Tambah record kedua untuk www (sama seperti di atas tapi Name: www)

#### **Namecheap:**
1. Dashboard → Domain List → Manage
2. Tab "Advanced DNS"
3. Add New Record:
   - Type: A Record
   - Host: @
   - Value: 178.128.59.20
   - TTL: Automatic
4. Add New Record untuk www

#### **GoDaddy:**
1. My Products → Domains → DNS
2. Add → A Record
   - Name: @
   - Value: 178.128.59.20
   - TTL: 600 seconds
3. Tambah A Record untuk www

### D. Tunggu DNS Propagation (5-60 menit)

DNS propagation bisa memakan waktu 5 menit sampai 24 jam (biasanya < 1 jam).

#### Cara Cek DNS Sudah Aktif:

**Option 1: Online Tool**
- Buka: https://dnschecker.org
- Masukkan: askcore.dev
- Cek apakah hasilnya menunjukkan: 178.128.59.20

**Option 2: Command Line**
```bash
# Windows (PowerShell)
nslookup askcore.dev 8.8.8.8

# Linux/Mac
dig askcore.dev @8.8.8.8
```

Jika sudah return `178.128.59.20`, DNS sudah aktif! ✓

## 🎯 Langkah 2: Setup HTTPS dengan Let's Encrypt

Setelah DNS aktif (askcore.dev sudah pointing ke 178.128.59.20), jalankan script HTTPS:

```bash
python setup_https.py
```

### Proses yang Akan Terjadi:

1. **Check DNS** - Verifikasi domain sudah pointing
2. **Install Certbot** - Tool untuk manage SSL certificate
3. **Update Nginx Config** - Configure web server untuk HTTPS
4. **Get SSL Certificate** - Request certificate dari Let's Encrypt (gratis!)
5. **Setup Auto-Renewal** - Certificate akan auto-renew setiap 60 hari

### Anda Akan Diminta:

1. **Konfirmasi DNS sudah ready** - Ketik: `yes`
2. **Email address** - Untuk notifikasi SSL expiry (masukkan email valid Anda)

## 🔧 Troubleshooting

### Problem: "DNS check failed"
**Solution:**
- Tunggu lebih lama (DNS propagation belum selesai)
- Cek DNS records di dashboard registrar sudah benar
- Test dengan: `dig askcore.dev @8.8.8.8`

### Problem: "Certbot failed to authenticate"
**Solution:**
- Pastikan port 80 dan 443 terbuka
- Cek Nginx running: `ssh root@178.128.59.20 "systemctl status nginx"`
- Restart Nginx: `ssh root@178.128.59.20 "systemctl restart nginx"`

### Problem: "Connection refused"
**Solution:**
- Cek firewall: `ssh root@178.128.59.20 "ufw status"`
- Allow ports: `ssh root@178.128.59.20 "ufw allow 80,443/tcp"`

### Problem: Certificate expired
**Solution:**
- Manual renewal: `ssh root@178.128.59.20 "certbot renew"`
- Check auto-renewal: `ssh root@178.128.59.20 "systemctl status certbot.timer"`

## 🔒 Security Best Practices (Opsional tapi Recommended)

### 1. Setup Firewall (UFW):
```bash
ssh root@178.128.59.20
ufw default deny incoming
ufw default allow outgoing
ufw allow ssh
ufw allow 80/tcp
ufw allow 443/tcp
ufw enable
```

### 2. Disable Root SSH Login (setelah setup SSH key):
```bash
ssh root@178.128.59.20
nano /etc/ssh/sshd_config
# Set: PermitRootLogin no
systemctl restart sshd
```

### 3. Setup Fail2ban (prevent brute force):
```bash
ssh root@178.128.59.20
apt-get install -y fail2ban
systemctl enable fail2ban
systemctl start fail2ban
```
